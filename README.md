# 李邦儀 Pang-Yi Lee — Official Website

A bilingual portfolio and editorial website for musician and media professional Pang-Yi Lee.

## Pages

- Home / 首頁
- About / 關於
- News
- Calendar
- Works / 影片與作品
- Projects
- Contact
- Content Studio / 後台內容管理

## Content management

Open `admin.html`, enter a GitHub fine-grained personal access token with **Contents: Read and write** access to this repository, edit the bilingual fields, and choose **儲存並同步前台**. The token is kept only in `sessionStorage` and is never committed.

All public content lives in `content.json`; the public site reads it directly. The project is fully static and GitHub Pages compatible.
